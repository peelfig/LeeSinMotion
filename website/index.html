极速安装生态

仅需三步，即可在不到一分钟内搭建属于您的现代动画追踪流。

1 下载并解压系统归档包。

请提取压缩包中的 com.bepeel.leesin.motion 文件夹与安装说明文件。

2 挂载扩展至 Adobe 原生目录。

# 将解压得到的整个文件夹拷贝入下列系统级路径： /Library/Application Support/Adobe/CEP/extensions/

3 一键授权：允许运行本地扩展 (首次安装必做)。

拷贝并运行下列复合指令一次性激活 2015-2025 全版本支持。运行后重启 AE 即可生效：

for i in {6..14}; do defaults write com.adobe.CSXS.$i PlayerDebugMode 1; done
