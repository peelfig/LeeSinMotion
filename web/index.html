Installation Guide (v4.0)

LeeSinMotion v4.0 is a CEP Extension. Please install the folder, not a script file.

Minimum Requirement: After Effects CC 2014 (v13.0)+

macOS

Move the `com.peel.leesin.motion` folder to:

/Library/Application Support/Adobe/CEP/extensions/

Run in Terminal: defaults write com.adobe.CSXS.11 PlayerDebugMode 1

Windows

Move the `com.peel.leesin.motion` folder to:

C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\

RegEdit: HKEY_CURRENT_USER\Software\Adobe\CSXS.11 add String PlayerDebugMode=1
