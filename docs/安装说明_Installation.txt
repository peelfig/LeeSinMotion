------------------------------------------------------------------------
[中文] 快速安装（三步完成）
------------------------------------------------------------------------

1. 复制插件文件夹
   将 "com.bepeel.leesin.motion" 文件夹复制到：

   Mac:     /Library/Application Support/Adobe/CEP/extensions/
   Windows: C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\

2. 开启调试模式（首次安装必做）

   Mac 用户 - 打开终端，运行：
   for i in {6..14}; do defaults write com.adobe.CSXS.$i PlayerDebugMode 1; done

   Windows 用户 - 以管理员身份运行 CMD，执行：
   for /L %i in (6,1,14) do reg add "HKEY_CURRENT_USER\Software\Adobe\CSXS.%i" /v PlayerDebugMode /t REG_SZ /d 1 /f

3. 重启 After Effects
   菜单栏：窗口 > 扩展 > LeeSinMotion

------------------------------------------------------------------------
[ENGLISH] Quick Installation (3 Steps)
------------------------------------------------------------------------

1. Copy Plugin Folder
   Move "com.bepeel.leesin.motion" folder to:

   Mac:     /Library/Application Support/Adobe/CEP/extensions/
   Windows: C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\

2. Enable Debug Mode (Required for first-time installation)

   Mac - Open Terminal and run:
   for i in {6..14}; do defaults write com.adobe.CSXS.$i PlayerDebugMode 1; done

   Windows - Run CMD as Administrator and execute:
   for /L %i in (6,1,14) do reg add "HKEY_CURRENT_USER\Software\Adobe\CSXS.%i" /v PlayerDebugMode /t REG_SZ /d 1 /f

3. Restart After Effects
   Menu: Window > Extensions > LeeSinMotion
